# 4.3.0 — A card for every dead end

**1 September 2026**

### ✨ New

- when something really is broken, one tap sends a report — what broke, where, and which version — to whoever can fix it

### 🛠️ Improved

- the error screen now looks like the rest of the app, and says what actually happened — an update that landed mid-session reads as an update, not a crash
- when a new version ships while you are mid-game, the app quietly refreshes itself once instead of dying on the next tap — and if the refresh does not help, it says so plainly rather than trying again

### 🐛 Fixed

- after an update, the app no longer hands the browser a web page where it asked for code — the crash that killed a screen with a MIME-type error minutes after a release
- a crash on the sign-in, practice, TV or share-link screens now shows the app's own card instead of a raw browser error page
- a single failure is counted once rather than once per redraw, so the first time something goes wrong you are no longer told a refresh has already been tried
