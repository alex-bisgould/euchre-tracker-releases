# 2.22.0 — A week and a day

**23 August 2026**

### ✨ New

- while the database is paused, the site still serves every stat it already had — Analytics, History, Trophies and Rivalry all keep working, with a note along the bottom saying which date the numbers run to
- add a game night to your own calendar — the file carries reminders a week and a day before, and the next-up banner now shows on the home page too

### 🛠️ Improved

- the year view shows every year at once, stacked and scrollable, so you can see which months you played across all of them without paging back a year at a time
- the original game-night charts are their own page again, "Track record" — the planner is now about what's coming up, and the stats about how often plans actually come off
