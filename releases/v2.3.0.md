# 2.3.0 — Trustworthy numbers

**15 August 2026**

### ✨ New

- "Ordered Up Alone" is now a single button on the upcard screen
- scrap a hand (No Ace, No Face, No Trump) straight from the upcard screen — no need to fake a trump call first
- the caller picker pre-selects the seat left of the dealer, and the lobby remembers your last team scenario
- Longest Game and Quickest Match records now populate — game duration is stamped the moment a game is won

### 🛠️ Improved

- Trophies and Rivalry pages are now reachable from the Analytics tab bar

### 🐛 Fixed

- ⌘Z now undoes the last hand from any phase, not just the tricks screen
- pressing D or C in round 2 no longer steals Daniel and Cory's caller keys — suit keys claim only the first press
- abandoned games no longer count as losses for all four players — Home and Analytics now agree: stats count completed official games only, with unfinished games shown separately
- games marked "unofficial" now have their hands excluded from all analytics, not just the win/loss record
- scrapped hands ("No Ace, No Face, No Trump") no longer count as trump calls or euchres against the locked-in caller — on Home, in analytics, and on the live "This Match" chalkboard
- a finished game no longer accepts more hands (from a stale tab, double-tap, or direct API call)
- undoing a hand re-checks the score to decide the winner instead of always clearing it
- hand entries are validated before recording — impossible trick counts, unknown players, and invalid suits are rejected
- four imported games had swapped euchre counts and a missed loner attempt — aggregates repaired from their hand history, and an empty abandoned game was removed
- re-importing a CSV no longer duplicates every game and hand — imports skip anything already in the database and report it as skipped
- win-by-2 games imported from V1 CSVs could record the wrong winner (the higher score now wins, not whoever hit 10 first)
- imported hand points are recomputed from the official scoring rules instead of trusting the CSV, with disagreements reported after import
- imported hands with an unrecognizable trump caller are skipped with a warning instead of being silently scored for the wrong team
- imported games now count loner attempts and euchres the same way live games do (loner counts included failed attempts only in live games before)
- the Game Nights page no longer errors on a fresh install — the one-time CSV bootstrap moved to an explicit import action
- "That Spot" is now recorded during live games at Jeremy's — the cursed south chair is auto-attributed with every hand (previously only CSV-imported games had it)
- production build errors that prevented compiling the app for deployment; the client is now fully type-checked on every build
