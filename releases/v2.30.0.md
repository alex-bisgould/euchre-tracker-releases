# 2.30.0 — Both tables

**30 August 2026**

### ✨ New

- the Cottage group now has a saved copy too, so both tables stay readable while the database is away

### 🛠️ Improved

- a rotation that ends level on wins is now settled on points difference, so it names a winner instead of shrugging — Alex and Cory had no titles at all before, despite finishing joint-top eight times between them
- every Analytics tab now has its own address — /analytics/seasons opens on Seasons, and Back undoes a tab click. Trophies and Rivalry are tabs too, so they no longer strand you on a page with no way back; their old links still work
- tapping the group name now drops down your other tables to switch straight to one, instead of loading the whole groups page — the full page is still one tap away

### 🐛 Fixed

- Rotations was empty on the hosted app — it read a field only the offline server sends, so it looked blank while working perfectly on a laptop. It now finds all 16 rotations in your history, including the two nights that were two rotations back to back
