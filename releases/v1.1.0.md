# 1.1.0 — Looking back

**November 2025**

> Before the changelog existed — reconstructed from the roadmap, so the record only pins this one to the month.

### ✨ New

- A History page grouping every match by date, with a card per game and the hand-by-hand table underneath.
- Sort newest or oldest first.
- Mark a game unofficial, declare a winner after the fact, or delete a match that should not have been recorded.
- The location shows as an icon beside the date.

### 🐛 Fixed

- History sorted the months alphabetically inside a year, so December came before February.
