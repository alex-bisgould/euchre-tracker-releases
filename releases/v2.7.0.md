# 2.7.0 — Three years, moved in

**19 August 2026**

### ✨ New

- share your group's stats with someone who has no account — create a named link (one each for whoever you like), send it, and revoke it whenever you want. They see the standings, history and records; they can't start a game or change anything.
- a game night played on the local app can still be pushed to the cloud after the cutover — the sync tool adds new matches and updates edited ones without duplicating the history already there
- three years of game history is now live in the cloud — all 59 games, 165 hands and 27 game nights, including the August 18th night at Daniel's
- groups have a readable web address — /g/cousins works as a real, bookmarkable link instead of a long id, and it keeps working if the group is ever renamed

### 🐛 Fixed

- player names now render as names everywhere in the cloud app — Match History showed raw database ids instead of "Jeremy & Cory", and team initials on the scoreboard would have shown digits instead of "J+C" the first time you tracked a game online
