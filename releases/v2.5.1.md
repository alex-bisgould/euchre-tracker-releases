# 2.5.1 — The cloud cutover

**17 August 2026**

*A patch number carrying an entire re-platform: twelve commits moved the app off local SQLite and onto Supabase Postgres behind a serverless API. The version was only nudged for the sign-in button polish that happened to land last.*

### ✨ New

- the app now runs against the cloud — group data, rosters, and locations load per group, with sign-in gating on the deployed site and a daily keep-alive so the database never sleeps before game night
- sign-in screen (Google, Apple, or email) behind a feature flag — the cloud database, security rules, and invite/claim machinery are live; local tracking is unchanged until launch

### 🛠️ Improved

- the Google and Apple sign-in buttons now carry their real logos and follow each vendor's button styling, inverting cleanly on the dark felt theme

### 🐛 Fixed

- sign-in no longer offers a provider that isn't configured — tapping Google or Apple used to replace the app with a raw error page and no way back
