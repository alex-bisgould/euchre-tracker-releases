# 2.15.0 — The things that never worked

**23 August 2026**

### ✨ New

- adding someone to a group offers the people you already play with, so the same friend across two groups stays one person — claiming an invite then takes over their seat in every group at once instead of leaving duplicates behind
- if you started a group you can now hand it over to someone else and leave — before, the Leave button was there but always failed, telling you to use a hand-over feature that didn't exist

### 🛠️ Improved

- you can see a group is nearly full before you try to add someone — the sixteen-player limit only ever showed up as an error after you'd typed the name
- the Features & Roadmap page is caught up — the last three releases are on it, the "last updated" line follows the app version instead of being typed in, and two status filters that could only ever come back empty are gone

### 🐛 Fixed

- the icon picker no longer offers a stranger's photo to unrelated groups — Howard's face is a Cousins picture and was being shown to everyone
- picking who's playing tonight explains itself — with more than four in the group, dropping below four left the team-scenario card blank with no hint that it was waiting on you
- people you share a link with can read the house rules and the roadmap — both buttons were hidden for them, because following either would have landed them on a sign-in page
- a place you add yourself now shows up in the Locations tab with the rest — offline only the five original houses were ever counted, so anywhere new stayed blank and its host never got a home-table record
- a retired player can be removed from the group without un-retiring them first — Remove only ever appeared on the active list
- Players and Places are reachable again when the app runs on your own machine — the menu holding both links only appeared once you were signed in, so offline the only way in was typing the address by hand
- a retired second table can be brought back — retiring one used to remove it from the places list, its own place's tables, and the Retired list all at once, so there was no way to undo it
- everyone in a big group gets their own colour — there were only eight to go round against a cap of sixteen, so the ninth member onwards was handed a colour someone already had, and removing anyone made two people match even in a small group
