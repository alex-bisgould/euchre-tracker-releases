# 2.0.0 — Out of the shoebox

**March 2026**

> Before the changelog existed — reconstructed from the roadmap, so the record only pins this one to the month.

*The app had been in use at game nights since the autumn. This is the month it stopped feeling like a tracker and started feeling like a record: a night theme, a rules page, and the analytics that answer arguments.*

### ✨ New

- Dark mode, and a 🌙 button to switch — the app is usually open on a table under a kitchen light, and the white page was the wrong thing to be looking at all evening.
- A Seasons tab: the year, the quarter and the month, each with its own standings, and a minimum number of games before anyone gets ranked.
- Caller vs Defender on the Overview — how often the calling team gets it home, how often the defenders take it off them, split by round one and round two.
- A Screw the Dealer stat: how many times the dealer was forced to call, and how often it worked out.
- Trump suit win rates — four cards showing whether spades really are worse than hearts.
- An Upcard tab: what everyone does with a nine versus an ace, which ranks get ordered up, which get turned down, and which produce loners.
- A Locations tab — win rates by house, host advantage, the favourite trump at each table, and which duo is cursed where.
- Fun Stats: results by day of the week, games per session, hands per game.
- A Game Nights planner, so the next night has a date on it before it happens.
- A README page in the app with the house rules and the scoring table, for when somebody new sits down.

### 🐛 Fixed

- The west chair sat off the edge of the rectangular tables.
- Games that went past 10 on a win-by-2 extension were credited to the wrong team.
