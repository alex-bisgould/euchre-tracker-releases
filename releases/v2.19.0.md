# 2.19.0 — The Night Itself

**23 August 2026**

### ✨ New

- a game night can carry the time you're playing — "7:30 to 10" — shown on the upcoming-night banner and beside each date, including nights that run past midnight
- a LAN game-night mode — run the whole tracker off the laptop on one port and let every phone at the table open it over the wifi, no internet and no cloud required
- the planner works out which nights actually happened from the games played that day, so a night nobody went back to mark now reads as happened with its game count — and it names the nights you played but never logged at all

### 🐛 Fixed

- clearing a location or a note on a game night now works on the hosted app; it only ever worked when running locally
