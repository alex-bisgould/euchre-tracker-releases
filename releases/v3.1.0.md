# 3.1.0 — Across the room

**31 August 2026**

### ✨ New

- the What's New page now starts in January 2025, nine months before the first line of code — the Google Sheet the tracker grew out of, its scoring formulas and the columns that became today's loner and bower stats, followed by the October build day by day
- the TV can now follow a game being scored on another device — tap 📺 on Track Game and scan the code with whatever screen you want the scoreboard on, over the internet with a share link or on the wifi at the table. A display tab in the same browser stays as instant as it always was

### 🐛 Fixed

- the October 2025 releases described a week that did not happen — timers, sound, locations and That Spot were never built that week and have moved to the winter, and the first night is no longer credited with a playable game it did not have
