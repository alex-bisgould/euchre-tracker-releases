# 0.0.6 — The loner rules

**21 March 2025**

> Before the changelog existed — reconstructed from the roadmap, so the record is thinner than the rest.

### 🐛 Fixed

- calling a loner and getting euchred pays the other team two points, not one
- taking all five tricks without going alone no longer pays four
- every outcome comes from one scenario table, so the same hand always scores the same
- hands whose numbers cannot have happened are flagged instead of quietly scored
