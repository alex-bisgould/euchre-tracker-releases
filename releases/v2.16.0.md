# 2.16.0 — One table, one way

**23 August 2026**

### 🛠️ Improved

- the four houses are now styled the same way as any table you build yourself, so their looks are editable instead of fixed — pick a different top or seat finish at Jeremy's and it sticks

### 🐛 Fixed

- the TV display draws each house's own table again when it hasn't loaded the group yet, instead of falling back to a plain green one
- the seating lobby now shows the table you are about to play on — it drew a plain green circle whatever the place looked like, so Jeremy's glass table and bench only appeared once the game started
