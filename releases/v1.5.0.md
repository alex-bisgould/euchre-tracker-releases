# 1.5.0 — Three years of Sundays

**December 2025**

> Before the changelog existed — reconstructed from the roadmap, so the record only pins this one to the month.

### ✨ New

- Import the old spreadsheets: a match-level CSV for the early years, and a hand-level one for the recent ones. The app works out which format it is looking at.
- Re-importing the same file does not double the database — anything already in there is skipped and reported.
- A result report after every import, so a bad row is visible rather than silent.
