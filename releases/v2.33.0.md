# 2.33.0 — Something to show for it

**30 August 2026**

### ✨ New

- End a game and hit QR to put the night on screen as a code — anyone at the table scans it and lands on that evening's games.
- A Stonewall badge for winning while holding the other team to 2 points or fewer — counted back through every game ever recorded, so it arrives with history already on it.
- Rotations now has an Honours card — who holds the title right now, the longest back-to-back run, and how many rotations it's been for everyone else.

### 🛠️ Improved

- While the games database is offline, controls that cannot work are now hidden rather than failing when pressed — adding or editing a game night, minting invite links, retiring or removing players, editing a place, and creating share links. A game-night change that does fail now says so instead of doing nothing at all.
