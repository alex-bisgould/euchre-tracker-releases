# 1.11.0 — For the TV

**February 2026**

> Before the changelog existed — reconstructed from the roadmap, so the record only pins this one to the month.

### ✨ New

- A full-screen spectator display for the television in the corner: the score, whose deal it is, and what phase the hand is in, refreshing twice a second.
- Badges on screen for a loner and for a paused match, so nobody has to ask.
- The leader's score glows, and a banner takes over the screen when the game is won.
