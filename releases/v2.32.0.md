# 2.32.0 — When the database is away

**30 August 2026**

### ✨ New

- `pnpm invites` lists who still has an unclaimed invite and can push their expiry past a pause, so nobody loses their link while the database is away.

### 🛠️ Improved

- The pause checklist now counts down the 90-day window for restoring a paused database, and no longer claims a daily alarm it cannot actually see.

### 🐛 Fixed

- Signing out while the games database is offline no longer strands you — the app warns you first, and your groups stay reachable from saved games instead of a dead end.
- An invite link opened while the database is offline is no longer written off as broken — it says to try again later and keeps the link, instead of deleting it.
- Shared stats links now say when the numbers are a saved snapshot instead of quietly showing old results as if they were live, and a vote link is no longer called dead when the database is simply offline.
- the group switcher no longer restarts its loading every time you close and reopen it — it asked again on each open and threw away the answer that was about to arrive, which on a slow connection looked like it never loaded at all
