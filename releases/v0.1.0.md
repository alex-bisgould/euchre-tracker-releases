# 0.1.0 — First deal

**19 October 2025**

> Before the changelog existed — reconstructed from the roadmap, so the record is thinner than the rest.

*Written from a specification the same evening. The server returned "Cannot GET /" on the first run and the analytics page crashed on the second. It recorded a hand, though.*

### ✨ New

- Start a game, record it hand by hand, and rotate the dealer automatically.
- First team to 10 wins, with a win-by-2 extension when it is that close.
- Undo the last hand, declare a winner by hand, and add a note or a quote to the match.
- Express and SQLite behind it, React and Vite in front, and a scoring engine that knows what a euchre is worth.
