# 2.10.0 — Every version, written down

**20 August 2026**

### ✨ New

- a What's New page at /whats-new — every release from v2.0 to today, with what changed in each, reached by tapping the version number in the header. The roadmap's version tags link straight to the release that shipped them.
- places and pictures can be edited on the local app too, not just the hosted one — the local database keeps its own places, seeded with the four houses, so a coffee shop added at the kitchen table works the same either way
- the lobby's location picker links straight to adding a place, which is where you actually notice you are somewhere new

### 🛠️ Improved

- retiring a place no longer blanks the location on games played there — History and Analytics still name it, and a Retired list on the places page brings it back

### 🐛 Fixed

- the sign-in, group picker and claim screens now open in dark mode when that is what you chose, instead of flashing light first
